# QGIS-Assignment
Caution - Even though some files are named 'Shimla'. The Terrain does not represent Shimla and was chosen randomly. 
I used QGIS to perform terrain analysis over a selected mountainous study area. I started with SRTM elevation data, created a study boundary, checked the CRS and reprojected the DEM to UTM Zone 43N.
I generated slope, hillshade and contour outputs to understand the terrain. I then classified slope into four categories and used these categories to develop a terrain cost model.
Finally, I created origin and destination points and prepared the cost surface for least-cost path analysis. The objective was to understand how GIS can support preliminary infrastructure planning by identifying routes that account for terrain difficulty rather than simply choosing the shortest distance."
